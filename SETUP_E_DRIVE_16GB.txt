═══════════════════════════════════════════════════════════════════════════════
WHAT THE CODE DOES (Key Features for Your Setup)
═══════════════════════════════════════════════════════════════════════════════

✓ Lazy Loading (preload=False)
  → Reads EDF files slice-by-slice from E: drive, not all at once
  → Stays within 16 GB RAM limit

✓ Streaming Approach
  → Processes one file at a time, frees memory immediately
  → Never accumulates all data in RAM

✓ SMOTE Applied (Class Imbalance)
  → Upsamples seizure windows (minority class)
  → Prevents model from learning to always predict "normal"
  → Only applied to training data (not test)

✓ GroupShuffleSplit (No Data Leakage)
  → Ensures patient's data stays in EITHER train OR test
  → Gives honest performance estimates

✓ Regularization (Prevent Overfitting)
  → L2 regularization on all layers
  → Dropout in CNN
  → Batch normalization
  → Early stopping monitors validation loss
  → Overfitting gap should be < 0.10

✓ Two Models for Comparison
  → Random Forest: Fast, interpretable baseline
  → 1D-CNN: Learns temporal patterns, usually better

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Error: "No summary files found"
  → Your data_dir path is wrong
  → Check E: drive structure and update data_dir in Cell 1

Error: "No EDF files found"
  → Same issue — verify the path and folder name

Memory Error / Computer Freezes
  → Close other apps (Chrome, Outlook, etc.)
  → The notebook is designed for 16 GB but needs some breathing room
  → If still crashes, try restarting and running again

MemoryError during SMOTE
  → SMOTE is memory-intensive
  → If this happens, set USE_SMOTE = False in the notebook
  → The model will use class_weight instead (still handles imbalance)

TensorFlow/CUDA warnings
  → Safe to ignore — GPU is optional, CPU works fine
